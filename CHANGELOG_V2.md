# TaskBridge v2.0 - Changelog

## 🎉 Новые возможности

### 1. **Множественные исполнители задач**
- ✅ Теперь можно назначать несколько исполнителей на одну задачу
- ✅ AI-экстрактор автоматически извлекает всех упомянутых пользователей
- ✅ Поддержка формата: `@user1 @user2 сделайте презентацию`
- ✅ Поддержка формата: `Саша и Маша, подготовьте отчет`
- ✅ Все исполнители получают уведомления о назначении задачи

**Технические изменения:**
- Добавлена таблица `task_assignees` (many-to-many связь)
- Обновлена модель `Task` с полем `assignees` (список)
- Обновлена модель `PendingTask` с полем `assignee_usernames` (JSON массив)
- AI промпт обновлен для извлечения массива username

### 2. **Уведомления о комментариях**
- ✅ При добавлении комментария к задаче все участники получают уведомление
- ✅ Уведомления отправляются создателю задачи и всем исполнителям
- ✅ Автор комментария не получает уведомление о своем комментарии
- ✅ В уведомлении есть кнопка "Открыть задачу" для быстрого перехода

**Технические изменения:**
- Создан модуль `bot/notifications.py` для отправки уведомлений
- API endpoint `POST /api/tasks/{task_id}/comments` теперь отправляет уведомления
- Добавлена функция `notify_comment_added()` в `bot/notifications.py`

### 3. **Фильтрация задач по создателю**
- ✅ API endpoint `/api/tasks` поддерживает параметр `created_by`
- ✅ Руководители видят только задачи, которые они создали
- ✅ Исполнители видят только задачи, назначенные им
- ✅ Разделение прав доступа между создателями и исполнителями

**Технические изменения:**
- Добавлено поле `created_by` в модель `Task`
- Добавлена связь `creator` (User) в модель `Task`
- API endpoint обновлен для фильтрации по `created_by`
- API ответы теперь включают информацию о создателе задачи

### 4. **Улучшения API**
- ✅ Endpoint `/api/tasks` возвращает `assignees` (массив) вместо `assignee`
- ✅ Endpoint `/api/tasks` возвращает `creator` (информация о создателе)
- ✅ Endpoint `/api/tasks/{task_id}` возвращает полную информацию об исполнителях
- ✅ Фильтрация по исполнителю работает через many-to-many связь
