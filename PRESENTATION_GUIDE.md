### **Открывающий слайд (30 секунд)**

> "Добрый день! Сегодня я представлю **TaskBridge** — AI-powered систему управления задачами для команд в Telegram.
>
> **Проблема:** В групповых чатах задачи теряются, неясно кто за что отвечает, нет контроля дедлайнов.
>
> **Решение:** TaskBridge автоматически извлекает задачи из переписки, назначает исполнителей, контролирует сроки и предоставляет веб-панель для мониторинга."

### **Демо-сценарий (2-3 минуты)**

#### **Шаг 1: Создание задачи** (30 сек)
```
1. Открываю Telegram группу
2. Пишу: "@alex сделай отчет по продажам до завтра к обеду, это срочно"
3. Бот присылает подтверждение:
   "🤖 AI обнаружил задачу!
    Задача: Сделать отчет по продажам
    Исполнитель: @alex
    Срок: 19.11.2025 13:00
    Приоритет: high"
4. Нажимаю "✅ Подтвердить"
```

**Что показать:**
- ✅ AI правильно извлёк всю информацию
- ✅ Понял естественный язык ("до завтра к обеду")
- ✅ Определил приоритет ("срочно" → high)

### **Технический стек (30 секунд)**

> "Проект построен на современном Python стеке:
> - **Backend:** Python + FastAPI + SQLAlchemy
> - **AI:** OpenAI GPT-4o-mini для извлечения задач
> - **Bot:** aiogram 3.3.0 (async framework)
> - **Frontend:** Vanilla JavaScript + Telegram WebApp SDK
> - **Deployment:** Railway.app (автоматический деплой)
> - **Database:** SQLite (dev) → PostgreSQL (prod)"

### **Ключевые фичи (1 минута)**

1. **AI-экстракция** 🤖
   - Понимает естественный язык
   - "до вечера" → 18:00
   - Автоопределение приоритета

2. **Умные уведомления** 🔔
   - Личные сообщения (если пользователь начал чат)

3. **Двойной WebApp** 📱
   - Manager mode (вся команда)
   - Executor mode (только мои задачи)

4. **Автонапоминания** ⏰
   - За 3 дня, 1 день, в день дедлайна

## ❓ Часто задаваемые вопросы

### **Q: Почему Telegram, а не Slack/Discord?**
A: Telegram популярен в СНГ, имеет отличный Bot API, бесплатные WebApps и не требует платной подписки.

### **Q: Почему polling, а не webhooks?**
A: Для MVP polling проще настроить и дебажить. Для production планируем webhook mode.

### **Q: Как обрабатываете ошибки AI?**
A: Есть fallback на keyword matching, если OpenAI недоступен. Плюс логирование всех AI ответов.

### **Q: Масштабируемость?**
A: Сейчас до 100 concurrent users. Для больше нужен PostgreSQL + webhook mode + horizontal scaling.

### **Q: Безопасность данных?**
A:
- Секреты в environment variables
- HTTPS для WebApp
- ORM защита от SQL Injection
- Планируем security audit перед production

### **Q: Стоимость разработки?**
A:
- Railway: Free tier ($5 credits)
- OpenAI API: ~$0.001 на задачу
- Время разработки: 3-4 дня (MVP)

### **Q: Можно ли использовать для больших команд?**
A: Да, но нужны доработки (PostgreSQL, webhook, rate limiting). Сейчас оптимально для 5-50 человек.
