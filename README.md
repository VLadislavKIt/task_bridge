# TaskBridge - Управление задачами из Telegram чатов

Прототип MVP-продукта для автоматического извлечения и управления задачами из групповых Telegram чатов.

## 🎯 Возможности

- 📨 Парсинг сообщений из групповых чатов
- 🔍 Автоматическое определение задач
- 👥 Назначение задач сотрудникам через @упоминания
- 🏷️ Автоматическая классификация задач по категориям
- 🔔 Уведомления исполнителей
- 📊 Веб-панель управления задачами
- 📱 Telegram Mini App для просмотра задач

## 🚀 Установка и запуск

### Шаг 1: Требования

- Python 3.10+
- Telegram аккаунт и доступ к @BotFather

### Шаг 2: Получение токена бота

1. Откройте Telegram и найдите [@BotFather](https://t.me/BotFather)
2. Отправьте команду `/newbot`
3. Следуйте инструкциям для создания бота
4. Скопируйте токен бота (например: `123456:ABC-DEF1234ghIkl-zyx57W2v1u123ew11`)

### Шаг 3: Создание конфигурации

Создайте файл `.env` в корне проекта или отредактируйте `config.py`:

**Вариант 1: Файл `.env`**

```env
BOT_TOKEN=ваш_токен_от_BotFather
DATABASE_URL=sqlite:///taskbridge.db
USE_WEBHOOK=False
PORT=8000
MINI_APP_URL=http://localhost:8000/webapp/index.html
```

**Вариант 2: Файл `config.py`**

```python
BOT_TOKEN = "ваш_токен_от_BotFather"
DATABASE_URL = "sqlite:///taskbridge.db"
USE_WEBHOOK = False
PORT = 8000
MINI_APP_URL = "http://localhost:8000/webapp/index.html"
```

### Шаг 4: Установка зависимостей

```bash
# Создайте виртуальное окружение (рекомендуется)
python -m venv venv

# Активируйте виртуальное окружение
# Windows:
venv\Scripts\activate
# Linux/Mac:
source venv/bin/activate

# Установите зависимости
pip install -r requirements.txt
```

### Шаг 5: Инициализация базы данных

```bash
# Создание таблиц и категорий
python db/init_db.py
```

Вы увидите:
```
✓ Таблицы созданы
✓ Категории инициализированы
✅ База данных успешно инициализирована!
```

### Шаг 6: Запуск бота

```bash
python main.py
```

Вы увидите:
```
Database initialized
Default categories initialized
Bot started in polling mode
Starting web app on 0.0.0.0:8000
Web app started in background thread
```

### Шаг 7: Открытие Telegram

1. Найдите своего бота в Telegram
2. Отправьте команду `/start` для начала работы
3. Добавьте бота в групповой чат
4. Дайте боту права администратора (рекомендуется)

### Шаг 8: Проверка работы

Отправьте сообщение в группу, например:

```
@username нужно сделать отчет до завтра
```

Бот должен:
- Извлечь задачу
- Сохранить в БД
- Уведомить @username (если он запустил бота через /start)
- Классифицировать задачу

Откройте веб-панель:
- Нажмите кнопку **"📋 Панель задач"** в боте
- Или перейдите на: `http://localhost:8000/webapp/index.html`

## 📋 Использование

### Команды бота

- `/start` - Начать работу (обязательно для получения уведомлений)
- `/help` - Справка
- `/panel` - Открыть веб-панель

### Система уведомлений

🔔 **Как работают уведомления:**
1. В групповом чате упоминается пользователь: `@username нужна помощь`
2. Бот извлекает задачу и ищет пользователя в базе данных
3. Бот отправляет уведомление пользователю в личные сообщения
4. Если пользователь не запустил бота (`/start`), бот отправит сообщение в групповой чат:
   ```
   👋 @username, пожалуйста, начни чат со мной (/start), 
   чтобы получать уведомления о задачах.
   ```
5. После `/start` пользователь будет получать все последующие уведомления в личные сообщения

### Ключевые слова для задач

Бот распознает сообщения, содержащие:
- "сделать", "нужно", "необходимо"
- "до", "к" (сроки)
- "важно", "срочно"
- "проверь", "убедись", "подготовь"
- и другие служебные слова

### Автоматическая классификация

Задачи автоматически классифицируются по категориям на основе ключевых слов в тексте:
- **Разработка** - код, git, commit, repo, bug, issue, deploy, api, database
- **Дизайн** - дизайн, макет, ui, ux, mockup, wireframe, figma
- **Маркетинг** - маркетинг, реклам, пост, smm, контент, campaign, seo
- **Аналитика** - аналитик, отчет, статистик, metric, dashboard, kpi
- **Встречи** - встреч, собрание, звонок, meeting, call
- **uncategorized** - если ключевые слова не найдены

## 🔧 Настройка для Production

### Webhook режим

1. Получите домен или используйте tunneling (ngrok)
2. Обновите `config.py`:

```python
USE_WEBHOOK = True
WEBHOOK_URL = "https://your-domain.com"
```

3. Установите SSL сертификат
4. Перезапустите бота

### PostgreSQL

Для production рекомендуется использовать PostgreSQL:

1. Установите PostgreSQL
2. Обновите `config.py`:

```python
DATABASE_URL = "postgresql://user:password@localhost/taskbridge"
```

3. Переустановите зависимости:
```bash
pip install asyncpg
```

## 📊 База данных

Проект использует следующие таблицы:

- **users** - Пользователи Telegram
- **messages** - Все сообщения из чатов
- **tasks** - Извлеченные задачи
- **categories** - Категории задач (с ключевыми словами для автоматической классификации)

Связи:
- Message → User (многие к одному)
- Task → Message (один ко многим)
- Task → Category (многие к одному)
- Task → User (исполнитель, многие к одному)

### Автоматическая классификация задач

Бот автоматически классифицирует задачи по категориям на основе ключевых слов:

- **Разработка**: код, програм, git, commit, repo, bug, issue, deploy, api, database, sql
- **Дизайн**: дизайн, макет, ui, ux, mockup, wireframe, figma, sketch
- **Маркетинг**: маркетинг, реклам, пост, smm, контент, campaign, advertising, seo
- **Аналитика**: аналитик, отчет, статистик, metric, dashboard, kpi, analytics
- **Встречи**: встреч, собрание, звонок, meeting, call, conference
- **uncategorized**: задачи без совпадений ключевых слов

Если существующая база не содержит поле `keywords` в таблице `categories`, удалите файл `taskbridge.db` и перезапустите бота для создания новой структуры.

## 🔐 Безопасность

- **НЕ коммитьте** файл `config.py` с реальными токенами в систему контроля версий
- Используйте переменные окружения для чувствительных данных
- Добавьте `config.py` в `.gitignore`
- Для production используйте HTTPS
