# 🌐 TaskBridge Web App

## Описание

Telegram Mini App для просмотра и управления задачами из групповых чатов.

## Доступ к приложению

### Через бота
1. Откройте чат с ботом TaskBridge
2. Отправьте команду `/start`, `/help` или `/panel`
3. Нажмите на кнопку **"📋 Панель задач"**
4. Веб-приложение откроется в Telegram

### Напрямую в браузере
```
http://localhost:8000/webapp/index.html
```

## Возможности

### 📊 Статистика
- **Всего задач** - общее количество задач
- **Ожидают** - задачи со статусом "pending"
- **В работе** - задачи со статусом "in_progress"
- **Завершено** - задачи со статусом "completed"

### 🔍 Фильтры
- **По статусу**: все / ожидают / в работе / завершено / отменено
- **По категории**: автоматическая фильтрация по всем категориям
- **По исполнителю**: выбор конкретного пользователя

### 📋 Отображение задач
Каждая задача показывает:
- **Название** - заголовок задачи
- **Описание** - полный текст задачи
- **Статус** - текущий статус задачи (цветная метка)
- **Категория** - к какой категории относится задача
- **Исполнитель** - кому назначена задача
- **Дата создания** - когда была создана задача

### 🔄 Обновление данных
- Кнопка **"🔄 Обновить данные"** для ручного обновления списка задач
- При обновлении автоматически перезагружаются все данные

## API Endpoints

### Получить список задач
```
GET /api/tasks
```

Параметры:
- `status` - фильтр по статусу (pending, in_progress, completed, cancelled)
- `category_id` - фильтр по категории
- `assigned_to` - фильтр по исполнителю

Пример:
```
GET /api/tasks?status=pending&category_id=1
```

### Получить статистику
```
GET /api/stats
```

Возвращает:
```json
{
  "total_tasks": 10,
  "pending_tasks": 5,
  "in_progress_tasks": 3,
  "completed_tasks": 2,
  "total_users": 5
}
```

### Получить категории
```
GET /api/categories
```

### Получить пользователей
```
GET /api/users
```

## Технологии

- **Frontend**: HTML5 + JavaScript + Telegram Web App SDK
- **Backend**: FastAPI
- **API**: RESTful JSON API
- **Дизайн**: Адаптивный, современный интерфейс

## Использование

### 1. Просмотр задач
Откройте веб-приложение и увидите все задачи из групповых чатов.

### 2. Фильтрация
Используйте фильтры в верхней части для поиска нужных задач:
- Выберите статус в выпадающем списке "Статус"
- Выберите категорию в выпадающем списке "Категория"
- Выберите исполнителя в выпадающем списке "Исполнитель"

### 3. Обновление данных
Нажмите кнопку **"🔄 Обновить данные"** для получения актуальной информации.

### 4. Просмотр деталей
Каждая карточка задачи содержит:
- Статус (цветная метка)
- Категорию (если назначена)
- Исполнителя (если назначен)
- Дату создания

## Цветовая индикация статусов

- 🔴 **Ожидает** - желтый фон (pending)
- 🔵 **В работе** - синий фон (in_progress)
- 🟢 **Завершено** - зеленый фон (completed)
- ⚫ **Отменено** - серый фон (cancelled)

## Мобильная оптимизация

Веб-приложение полностью адаптировано для мобильных устройств и оптимизировано для работы в Telegram Mini App.
